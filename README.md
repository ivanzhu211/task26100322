# task26100322-a 进程行为链检测库

Go 库,由上层直接调用,无接口层;规则、运行状态与命中证据全部保存在内存。

## 用法

```go
eng := chaindet.NewEngine(rules)        // 一次载入规则,运行期间不变
alerts := eng.Ingest(events)            // 分批摄入遥测,返回本批次新告警
score := eng.Score(processID)           // 查询进程总分、已命中规则及证据
```

## 语义

- 每条规则为同一进程、同一对象上按摄入顺序排列的三个不同事件,
  行为类型逐阶段匹配,两个相邻时间差分别落入闭区间等待范围,
  首尾时间差不超过最长跨度。
- 同一规则对一个进程终身只计一次分;命中时点为首个能完成合法组合的事件。
- 进程总分首次从低于 25 达到或超过 25 时产生一条 Critical 告警,
  分数包含该事件的全部贡献;每进程最多告警一次;批次划分不影响结果。

## 实现要点

- 规则按阶段行为类型建索引,事件只触达相关规则。
- 每个 (进程, 规则) 维护按时间升序的阶段一候选队列与阶段一二部分链队列,
  惰性剪枝、摊还 O(1);阶段二只保留对同一 e2 最晚的合法 e1。
- 单事件按 阶段三判定 -> 阶段二配对 -> 阶段一登记 的顺序处理,
  保证同一事件不会在一次命中中充当两个阶段。

## 测试

```sh
go test ./chaindet/ -count=1
```

覆盖:交错进程/对象下的命中与证据隔离、同时间戳与区间端点、
事件不可复用为两个阶段、多规则同事件命中只告警一次、批次划分不变性、
随机工作负载与朴素 O(n^3) 参考实现对拍,以及
5000 规则 / 200 进程 / 50 万事件的性能与内存验收。
