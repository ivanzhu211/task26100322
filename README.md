# chaindet

进程行为链检测库（Go，纯内存，无外部依赖）。由上层直接调用，无接口层。

## 用法

```go
eng := chaindet.NewEngine()
err := eng.LoadRules(rules)      // 一次载入，运行期间不变
alerts := eng.Ingest(events)    // 分批摄入，返回本批新告警
score, hits := eng.Query(proc)  // 查询进程总分、已命中规则及证据
```

## 语义

- 一次命中：同一进程、同一对象的三个不同事件按摄入顺序组成，
  类型逐阶段匹配，相邻时间差落入对应等待区间（含边界），
  首尾跨度不超过 MaxSpan（含边界）。
- 每条规则对每个进程终身只计一次分；同一事件新命中的全部规则共同贡献分数。
- 总分首次从低于 25 达到或超过 25 时产生一条 Critical 告警，
  每进程最多一次；批次划分不影响命中时点、得分与告警。
